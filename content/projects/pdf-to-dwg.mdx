## Problem

Legacy plant documentation often exists only as scanned PDFs — photographs of old paper drawings. Re-draughting these by hand is expensive; clients need editable, layered DWG files for current projects.

## Approach

The pipeline processes scanned PDFs through an image enhancement stage (deskew, contrast, noise reduction), then applies line detection to identify drawing geometry, OCR for text extraction, and generates structured AutoCAD entities. Output is a layered DWG file with geometry on separate layers and text blocks properly associated.

## Result

Conversion that previously required 2–3 days of manual draughting per drawing set is now a supervised automated process taking hours, with a quality-check step rather than a redraw step.
