## Problem

Understanding what's in a video feed in real time — classifying objects, counting items, flagging anomalies — requires ML infrastructure that's typically complex to deploy and expensive to run in the cloud.

## Approach

Using Apple's Vision framework and Core ML, the app runs on-device inference against a live camera feed. Custom models trained with Create ML classify objects relevant to engineering inspection contexts. Everything runs locally — no cloud round-trip, no latency, no data leaving the device.

## Result

Real-time classification at 30fps on an iPhone or iPad, with custom model support for domain-specific objects. The foundation for AR overlays and automated inspection flagging.
